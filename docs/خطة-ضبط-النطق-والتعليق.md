# خطة ضبط صحة النطق والتعليق — FINIX Voice Studio

**الإصدار:** 1.4.0 · **التاريخ:** ٢٥ نوفمبر ٢٠٢٦
**النطاق:** ضبط النطق والمعنى والإلقاء من أول جولة توليد، لا بعد السماع وإعادة العمل.

---

## ١. الهدف والمعايير

الهدف ليس «صوتاً مسموعاً»، بل تعليق يصل للمستمع بالمعنى الصحيح والنبرة المناسبة من المحاولة الأولى.

| المعيار | التعريف | حد القبول |
|---|---|---|
| صحة النطق | كل كلمة تُنطق بشكلها المقصود (حركات، همزات، اختصارات، أرقام) | لا كلمة عالية الخطورة بلا تشكيل أو قاموس |
| صحة المعنى | الإلقاء لا يغيّر معنى الجملة (سؤال ≠ خبر، تحذير ≠ سرد) | نية كل جملة مطابقة لعلامتها وسياقها |
| ملاءمة الأداء | نوع المحتوى والجمهور يحدّدان الصوت والنمط والطاقة | صوت ونمط مبرَّران من النص |
| الإيقاع | وقفات عند حدود المعنى، لا حشو صمت | لا تجاوز للهدف الزمني > ٥٪ في وضع «مطابق بالثانية» |
| الاتساق | نفس النص = نفس النطق في المعاينة والتوليد الكامل | نفس الصوت والنمط والقيم |

---

## ٢. ما يعمل الآن (الجولة الأولى — منفَّذة في 1.3/1.4)

```
نص
 → مدير الاستوديو: نوع المحتوى + الجمهور + النبرة + الصوت + النمط + الشدة
 → خطة النطق: اختصارات وأرقام وإملاء وكلمات ملتبسة وكلمات أجنبية مجهولة
 → تطبيع لغوي per-sentence (أرقام، عملات، تواريخ، هاشتاق، إملاء)
 → تشكيل هجين: نموذج محلي + قاموس سعودي مضبوط يدوياً + وقف إعرابي
 → خطة أداء: نية كل جملة + جُمل فرعية + وقفات + إبراز الكلمات المفتاحية
 → توليد + قصّ صمت الأطراف + قياس + مطابقة مدة + تركيب + SRT
```

**المكوّنات الجديدة:**

- `lib/director.mjs`: يفهم النص ويختار الصوت/النمط/الشدة، ويستخرج الإبراز وخطة النطق.
- `lib/lexicon.mjs`: توسيع النطق العربي للاختصارات (`KPI`, `ROI`, `CTA`, `SMS`, `GPS`...).
- `lib/intent.mjs`: الإبراز يخفّض السرعة ٤٪ ويرفع الطبقة ٤ وحدات للجملة الحاملة للمعنى.
- `POST /api/director` + بطاقة «مدير الاستوديو» في الواجهة.
- `settings.director = "off"` لإيقافه، وأي اختيار صريح من المستخدم يتقدّم عليه.

## ٣. بوابات الجودة من أول جولة

تُنفَّذ بالترتيب، وأي بوابة فاشلة توقف التوليد أو تُعلن السبب صراحةً.

### Gate 0 — جاهزية البيئة
- `GET /api/health` = 200 (بايثون، `edge-tts`، المشكّل، ffmpeg).
- فشل المشكّل لا يمنع التوليد لكن يُعلن الانتقال إلى «قاموس اللهجة فقط».

### Gate 1 — جودة النص
- مراجعة `reviewText`: أخطاء إملائية = 0، فصحى داخل نص سعودي = 0، جمل > ١٦٠ حرفاً = 0.
- درجة المراجعة ≥ ٨٥ أو موافقة صريحة من المستخدم.

### Gate 2 — جاهزية النطق
- `pronunciation.score ≥ 75` وإلا يُعرض تقرير «راجع النطق قبل التوليد».
- كل كلمة أجنبية داخل جملة عربية: إمّا في قاموس النطق أو تُقترح إضافتها.
- كل كلمة ملتبسة (سلم/علم/كتب/ملك...): تظهر للمستخدم مع بدائلها المشكَّلة.
- الأرقام والتواريخ والعملات: تُحوَّل آلياً ويُعاد عرض النص المنطوق للتأكيد.
- الجمل الإنجليزية الخالصة تُستثنى من فحص «الكلمة الأجنبية» لأنها تُنطق بصوت إنجليزي.

### Gate 3 — ملاءمة الأداء
- نوع المحتوى والجمهور والنبرة معروضان مع سبب الاختيار.
- الإبراز محصور في الكلمات الحاملة للمعنى (السر، الفرق، مستحيل، مجاناً، لا...).
- لكل جملة دور: افتتاحية / جسم / خاتمة، ولكل دور قيم نطق مختلفة.

### Gate 4 — الصوت والتوقيت
- صمت الأطراف مقصوص (رأس ٢٠ مللي، ذيل ٦٠ مللي) قبل القياس.
- خطأ المدة ≤ ٥٪ في الوضع المطابق، و≤ ٠٫٥ ثانية في الطبيعي.
- SRT يطابق نهاية الصوت الفعلي، وملف لكل مقطع يُراجع منفصلاً.

## ٤. منهجية الاختبار

### مجموعة ذهبية (Golden Set)
٤٠ جملة موزّعة: إعلان، شرح، خبر، قصة، كوميديا، تحفيز، وثائقي، مراجعة، مختلط عربي/إنجليزي، وأرقام وتواريخ وعملات.

لكل جملة يُسجَّل:
1. النص الأصلي.
2. النص المنطوق المتوقع (تشكيل + قاموس).
3. النوع/الصوت/النمط المتوقع.
4. المدة المتوقعة ± ٠٫٣ ث.
5. حكم الاستماع: صحيح / مقبول / خطأ + السبب.

### قياسات آلية متاحة اليوم
| القياس | المصدر | الاستخدام |
|---|---|---|
| `review.score` | `lib/qa.mjs` | جودة اللغة واللهجة |
| `pronunciation.score` | `lib/director.mjs` | مخاطر النطق |
| `diacriticCoverage` | `lib/tashkeel.mjs` | نسبة الحركات (مؤشر لا حكم) |
| `timingErrorPercent` | `lib/render.mjs` | دقة المدة |
| عدد الوحدات المُعاد توليدها | `stats.unitsCached` | كفاءة الكاش والاتساق |

### قياس الاستماع
لا يوجد ASR في المشروع، لذلك الحكم النهائي بشري على عيّنة. تُدار جلسة استماع عمياء: تُسمَّى الملفات بأرقام لا بأسماء إعدادات، ويُقيَّم كل ملف من ١–٥ في: النطق، المعنى، النبرة، الإيقاع. **لا يُعلن تحسّن بلا هذه الجلسة.**

### اختبار الانحدار
`npm test` (٧١ اختباراً) + فحص حي عبر `.tmp/checks/e2e.mjs`: تحليل → معاينة → مهمة كاملة → MP3/SRT.

## ٥. جولات التطوير

### الجولة ١ — الأساس (منفَّذة)
- مدير استوديو يقرأ النص ويوجّه الأداء.
- خطة نطق تكشف المخاطر بدل ادّعاء معرفة كل نطق.
- إبراز الكلمات المفتاحية في النبرة.
- استثناء الجمل الإنجليزية من فحص الأجنبي.
- توسيع اختصارات النطق العربي.

### الجولة ٢ — عمق النطق (التالي)
1. **قاموس الملتبسات السياقي:** اختيار الشكل تلقائياً من السياق (بعد «أن» فعل، بعد «ال» اسم) مع إظهار الثقة، لا تغيير صامت.
2. **مراجعة النطق بعد التشكيل:** كشف الكلمات التي بقيت بلا حركة داخل جملة مشكَّلة، وإعادة تشكيلها وحدها.
3. **توسيع أسماء الأعلام والمدن والشركات** في `GULF_TASHKEEL` و`PRONUNCIATION`.
4. **تقرير نطق قابل للتصدير** (JSON/CSV) لكل كلمة: كما كُتبت، كما نُطقت، المصدر (نموذج/قاموس/تصحيح).

### الجولة ٣ — قياس موضوعي
1. **حلقة ASR اختيارية:** تفريغ الصوت الناتج ومقارنته بالنص المنطوق (CER/WER). تُفعَّل فقط عند توفر محرك تفريغ محلي، وتبقى خارج المسار الافتراضي.
2. **كشف الحروف المبتلعة والمدة الشاذة:** مقارنة مدة كل وحدة بمتوقعها من عدد المقاطع، ورفع علم على الانحراف الكبير.
3. **معايرة النبرة حسب المنصة:** ريلز/يوتيوب/بودكاست، بأهداف طاقة وسرعة مختلفة.

### الجولة ٤ — تشغيل الاستوديو
1. واجهة اعتماد: «اعتمد خطة النطق» قبل التوليد الجماعي.
2. قوالب نطق محفوظة لكل عميل/براند.
3. تقرير جودة لكل مهمة يُحفظ في `out/<jobId>/report.json`.

## ٦. مؤشرات القبول (KPIs)

| المؤشر | الحالي | هدف الجولة ٢ | هدف الجولة ٣ |
|---|---|---|---|
| نصوص بلا ملاحظة نطق | ١٠٠٪ في النص النظيف | ١٠٠٪ | ١٠٠٪ |
| كلمات أجنبية مجهولة تُكتشف | كلها | كلها + اقتراح نطق | كلها + نطق تلقائي |
| دقة المدة (exact) | ≤ ٥٪ | ≤ ٣٪ | ≤ ٢٪ |

| أخطاء معنى الإلقاء | ٠ في المجموعة الذهبية | ٠ | ٠ |

## ٧. المخاطر والحدود

- **النطق ليس علماً مكتملاً آلياً:** الأسماء الغريبة والملتبسات لا تُحلّ بلا معجم؛ النظام يكشفها ويطلب قراراً، ولا يخمّن بصمت.
- **التشكيل نموذجي:** قد يخطئ في العامية؛ قاموس اللهجة هو خط الدفاع، وتوسيعه هو الاستثمار الأعلى مردوداً.
- **المحرك سحابي غير رسمي:** قد يتغير أو يحدّ الطلبات؛ خطة الاعتماد التجاري تتطلب Azure Speech عبر `lib/tts.mjs`.
- **لا ASR بعد:** القياس الموضوعي للنطق مؤجّل للجولة ٣، والحكم اليوم بشري موثّق.
