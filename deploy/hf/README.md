# SAWTIX — استوديو التعليق الصوتي من FINIX

استوديو عربي لتوليد التعليق الصوتي: يفهم النص أولاً (نوع المحتوى، الجمهور، النبرة)،
يختار الصوت والنمط، يضبط النطق والتشكيل، ثم ينتج MP3 + SRT بتوقيت دقيق.

> ملاحظة: مساحات Docker على Hugging Face تتطلب خطة مدفوعة (PRO للفرد). المساحات الثابتة فقط مجانية.

## التشغيل على هذه المساحة

- الصورة تُبنى من `Dockerfile` في جذر المساحة.
- المنفذ: `7860` (يضبطه `PORT`).
- المحرك: Node + Python (`edge-tts`, `text2tashkeel`) + ffmpeg — كلها داخل الصورة.
- أول تشغيل قد يستغرق دقائق (بناء الصورة وتحميل نموذج التشكيل).

## الحماية

- اجعل المساحة **Private** إن كانت للاستخدام الشخصي؛ عندها لا يدخلها إلا حسابك.
- للاستخدام العام أو المشاركة: أضف في **Settings → Variables and secrets**:
  - `APP_USER` (اختياري، الافتراضي `admin`)
  - `APP_PASSWORD` (إلزامي للنشر العام)
- عند ضبط `APP_PASSWORD` تُحمى كل الصفحات والمسارات، ويبقى `/api/health` مفتوحاً لفحص المنصّة.

## ملاحظات

- التخزين مؤقت: ملفات التوليد داخل `out/` وتُحذف مع إعادة تشغيل المساحة.
- الخدمة تنام بعد فترة خمول على الخطة المجانية وتستيقظ عند أول زيارة.
- `edge-tts` يستخدم خدمة القراءة الصوتية غير الرسمية من مايكروسوفت؛ للاستخدام التجاري الكثيف يُنصح بمحرك رسمي.
